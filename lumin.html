LUMIN

An analog dimming floor lamp

Performance of Light

CMF Design

This project was result of a lighting class with the design brief "Performance of Light." To help narrow the scope, I defined 'performance' to be dimmability'. I want my light to be dimmable, but purely through the user's analog interaction with it.

Performance by physics:
Dimmable lights without dimmable bulbs

The first step to answer the design brief, was to find different analog methods to making light dimmable. I've always been fascinated by camera's mechanism, and explored how the user can interact with a shutter.

Another exploration was through materials. Clear acrylic has a nice transmission of light, and gives interesting effects as the light pulls away and comes closer.

PROBLEM
SOLVING

To get the light performance I wanted, there were three main problems that needed to be solved

Exact right height

How can we make the lamp stay at the height exactly at where the user wants it to be?

Wire Problem

How can we keep the wire outside static, while the user is constantly pulling the light up and down?

Off/On Switch

Does it make sense to have a button?
